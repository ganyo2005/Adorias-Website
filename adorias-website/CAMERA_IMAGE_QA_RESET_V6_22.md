# Camera Image QA Reset — V6.22

The previous camera image layer has been removed from all 55 camera-body listings because spot checks found materially incorrect or unacceptable imagery.

## Regression checks that must pass before images are restored
- Nikon D810: must be an exact D810 camera image; previous mapping rendered an unrelated phone image.
- Nikon D850: exact D850, customer-facing product presentation; previous image rejected.
- Canon EOS RP: must be restored with an exact RP image, preferably a confirmed kit-lens configuration where appropriate.
- Nikon Z6: must receive an exact Z6 image.
- Nikon Z5: must receive an exact Z5 image.
- No image is approved merely because its URL or filename contains the model name.
- Each restored image must be visually checked for product identity and presentation.
- Kit-lens imagery is preferred only when the pictured kit is a real/confirmed configuration.

## Reset result
55/55 camera-body listings are now intentionally withheld from the old image layer. This prevents known-bad imagery from remaining customer-facing while the clean image set is rebuilt.
