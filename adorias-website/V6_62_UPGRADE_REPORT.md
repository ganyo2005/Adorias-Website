## Efia correction
The diagnosis path now locks recommendations to the diagnosed product domain before scoring. A camera/livestream request cannot return paper, printing, batteries or unrelated categories as camera candidates. Church livestreaming prioritizes documented video/output/production evidence. Hard requirements reject non-matches instead of merely lowering their score. Budget is remembered but is not falsely enforced until current selling-price data exists.

## Customer accounts
A polished account-feature preview has been added for order history, delivery tracking, My Gear, saved products, compatibility help, and receipts/support. It is intentionally marked backend-pending: real login, purchase history and shipment tracking require authentication, order storage and courier/order-system integration and are not faked in static frontend code.

## Homepage colour
The dynamic homepage keeps the existing premium neutral scheme but now introduces restrained warm bronze, muted blue-grey and soft olive accents through gradients, chips and ambient motion rather than changing the brand identity.
